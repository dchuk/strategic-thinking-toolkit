# strategic-thinking-toolkit (marketplace)

A [Claude Code](https://docs.anthropic.com/en/docs/claude-code) plugin marketplace hosting the **strategic-thinking-toolkit** plugin — a structured implementation of the Up–Down–Push Rollercoaster from Fred Pelard's *How to Be Strategic*.

## Install

```bash
claude plugin marketplace add dchuk/strategic-thinking-toolkit
claude plugin install strategic-thinking-toolkit@strategic-thinking-toolkit
```

The first command registers this repo as a marketplace; the second installs the plugin from it (`<plugin-name>@<marketplace-name>`).

## Plugins in this marketplace

| Plugin | Version | Description |
|---|---|---|
| [strategic-thinking-toolkit](strategic-thinking-toolkit/) | 0.1.0 | Up–Down–Push Rollercoaster framework, ten named strategy tools, two agents (planner, reviewer), and a facilitator skill. See the [plugin README](strategic-thinking-toolkit/README.md) for full usage. |
