# How to Be Strategic — Strategic Thinking Toolkit

A navigation hub for Fred Pelard's ten strategic tools, organized across the **Up–Down–Push Rollercoaster of Strategic Thinking**. This skill is for facilitators, strategists, and team leads who are about to run a strategy session, evaluate a strategic plan, or sequence a project from Complexity Corner to Conviction Corner.

---

## Is This Problem Truly Strategic?

Before choosing a tool, confirm the problem qualifies. A truly strategic issue meets most of these conditions (see [Strategic Mindset](references/core/strategic-mindset.md)):

| Condition | Check |
|---|---|
| The problem is big | ✓ |
| It lies in the future | ✓ |
| It has never been done before | ✓ |
| There will be very little data | ✓ |
| The best answer is not just a matter of taste | ✓ |
| It will require proof to convince many stakeholders | ✓ |

If most boxes are checked → use the **Rollercoaster**. If not, see [Four Routes to Completion](references/core/rollercoaster-framework.md) to pick the right route.

## Which Route to Completion?

| Route | When to use | Key reference |
|---|---|---|
| **Staircase** of Expert Execution | Answer already known; execute methodically | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |
| **Submarine** of Analytical Research | Turn unknowns into facts; data-first | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |
| **Helicopter** of Creative Discovery | Impose structure on chaos; 3–4 options in ~5% of time | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |
| **Rollercoaster** of Strategic Thinking | Helicopter first → Submarine → Push; optimal for strategic issues | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |

## Phase–Tool Mapping Table

The Rollercoaster has three phases. Every tool belongs to exactly one phase.

| Phase | Goal | Tools | One-line summary |
|---|---|---|---|
| **Up** (Generate Great Ideas Quickly → Clarity) | Reach the Clarity Corner fast | [Pyramid Principle](references/tools/pyramid-principle.md) | Structure any qualitative issue; MECE decomposition |
| **Up** | | [Happy Line](references/tools/happy-line.md) | Rank KPCs, draw the Lazy-L, identify Front/Top/Back zones |
| **Up** | | [Mutation Game](references/tools/mutation-game.md) | Build a mutation grid; generate unexpected idea combinations |
| **Down** (Eliminate Options in No Time → Certainty) | Reach the Certainty Corner methodically | [Payoff Profiles Matrix](references/tools/payoff-profiles.md) | Plot initiatives on the 3×3 Postures×Bets grid; Four Decisions |
| **Down** | | [Landscape Analysis](references/tools/landscape-analysis.md) | Mekkos, GPS Charts, Conversion Waterfalls, XLP |
| **Down** | | [Lean Startup](references/tools/lean-startup.md) | Build–Measure–Learn loop; MVP design; actionable vs vanity metrics |
| **Push** (Get the Best Solution Approved → Conviction) | Win stakeholder Conviction | [Impactful Words](references/tools/impactful-words.md) | NLP representation systems; match communication channel to audience |
| **Push** | | [Simple Numbers](references/tools/simple-numbers.md) | Balanced Scorecard; 12-metric cap; bouncer method; glide paths |
| **Push** | | [Compelling Story](references/tools/compelling-story.md) | Adland Swagger; three-word summary; Pyramid with Conviction |

## Anti-Pattern Quick Reference

> Full catalog: [Anti-Patterns Catalog](references/anti-patterns/anti-patterns-catalog.md)

| Anti-pattern | Why harmful | Reference |
|---|---|---|
| **Reserve Big Bet** | Keeps a fatally flawed option alive in the Payoff Profiles Matrix instead of destroying it | [Payoff Profiles Matrix](references/tools/payoff-profiles.md) |
| **HiPPO Curse** | Highest-paid person's opinion overrides structured analysis; short-circuits Down phase | [Anti-Patterns Catalog](references/anti-patterns/anti-patterns-catalog.md) |
| **Data-holic** | Hoards data in the Submarine instead of surfacing to test ideas; delays Conviction indefinitely | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |
| **Complexity Corner paralysis** | Team stays at the start; no Helicopter lift-off; zero Clarity produced | [Rollercoaster Framework](references/core/rollercoaster-framework.md) |
| **Lazy-L ignored** | KPCs ranked but the Lazy-L curve is not drawn; Front/Top/Back zones never identified | [Happy Line](references/tools/happy-line.md) |
| **Fourth Post-it (Rule 3 violation)** | Adding a fourth Post-it to a MECE branch destroys structural integrity of the Pyramid | [Pyramid Principle](references/tools/pyramid-principle.md) |
| **Vanity metrics** | Metrics that look impressive but cannot drive a decision; wastes the Lean experiment | [Lean Startup](references/tools/lean-startup.md) |
| **Mutation grid too narrow** | Fewer than 5 components or fewer than 2 variants per component; kills combinatorial power | [Mutation Game](references/tools/mutation-game.md) |
| **Adland Swagger without substance** | Three-word slogan chosen before the Pyramid is solid; persuasion without Certainty | [Compelling Story](references/tools/compelling-story.md) |
| **Wrong representation channel** | Presenting in Visual language to a Digital audience (or vice versa); message does not land | [Impactful Words](references/tools/impactful-words.md) |
| **Scorecard bloat** | Balanced Scorecard exceeds 12 metrics; bouncer method skipped; metrics lose memorability | [Simple Numbers](references/tools/simple-numbers.md) |

## What Would You Like to Do?

- **Diagnose my problem** — figure out whether it is truly strategic and which Route to Completion to use → run [`/diagnose-route`](../../commands/diagnose-route.md)
- **Build a Pyramid** — structure a qualitative issue with MECE logic and sufficient conditions → run [`/build-pyramid`](../../commands/build-pyramid.md)
- **Run a Happy Line session** — identify and rank KPCs, draw the Lazy-L, find the winning zone → run [`/run-happy-line`](../../commands/run-happy-line.md)
- **Run a Mutation Game** — craft the descriptive sentence, build the mutation grid, shortlist combinations → run [`/run-mutation-game`](../../commands/run-mutation-game.md)
- **Score my initiative portfolio** — plot on the Payoff Profiles Matrix, apply the Four Decisions → run [`/run-payoff-profiles`](../../commands/run-payoff-profiles.md)
- **Design a Lean experiment** — identify critical hypotheses, spec an MVP, choose actionable metrics → run [`/design-lean-experiment`](../../commands/design-lean-experiment.md)
- **Write an executive summary** — flyer format with Adland Swagger slogan and Pyramid structure → run [`/write-executive-summary`](../../commands/write-executive-summary.md)
- **Build a scorecard** — generate Balanced Scorecard candidates, apply the bouncer method, set glide paths → run [`/build-memorable-metrics`](../../commands/build-memorable-metrics.md)
- **Review a full strategic plan** — end-to-end critique against the Rollercoaster criteria → use the [Strategy Reviewer agent](../../agents/strategy-reviewer.md)
- **Plan a strategy project** — sequence the Up–Down–Push Rollercoaster for a specific challenge → use the [Strategy Planner agent](../../agents/strategy-planner.md)
