# Run Payoff Profiles Matrix

**Purpose:** Facilitate a structured Payoff Profiles Matrix session that maps 10–20 strategic initiatives onto a 3×3 Postures×Bets grid, applies the Four Decisions (Delegate/Destroy/Discuss/Drag), and engineers Glide Paths that move every initiative as close as possible to the Shape Options cell. Use this command during the **Down phase** of the Rollercoaster whenever a team needs to prioritize and de-risk a portfolio of strategic options.

**When to use:**
- You have 10–20 strategic initiatives to classify, prioritize, and improve
- The senior team is debating which initiatives deserve attention and which should be delegated or killed
- One or more initiatives feel like high-stakes gambles with uncertain differentiated reward (potential Reserve Big Bets)
- The portfolio lacks balance between risk and reward and needs a structured optimization pass
- You are mid-Rollercoaster and have completed an Up-phase tool (Pyramid Principle, Happy Line, or Mutation Game) that generated candidate initiatives to evaluate

---

## Steps

### 1. Gather the Initiative List (5 min)
Read any file or argument the user supplied. If no file was provided, ask the user to paste or describe all current strategic initiatives in scope. Compile a comprehensive list. Confirm the count — if there are more than 15, note that the digital app at www.strategic.how/payoff is recommended (see Decision Rule: Use App vs. Paper below).

### 2. Label the Initiatives (5 min)
For each initiative, propose a catchy name of **one to four words** that the team can use on a Post-it. Present the full labelled list to the user and ask for any corrections before proceeding.

### 3. Draw and Explain the 3×3 Grid
Render or describe the Payoff Profiles Matrix as follows:

```
           SHAPE    |   ADAPT   |  RESERVE
         ───────────┼───────────┼──────────
BIG BETS  [Discuss] |           | [DESTROY]
         ───────────┼───────────┼──────────
OPTIONS   [TARGET ★]|           |
         ───────────┼───────────┼──────────
NO REGRETS[Delegate]| [Delegate]| [Delegate]
```

- **Columns (Postures / Reward axis, left = high reward):**
  - **Shape** — seeks industry leadership, sets standards, creates demand
  - **Adapt** — fast second-mover, captures existing opportunities
  - **Reserve** — minimal investment to stay in the game, avoids premature commitment
- **Rows (Bets / Risk axis, bottom = low risk):**
  - **No Regrets** — positive outcome in any scenario
  - **Options** — small upfront cost, rare large upside
  - **Big Bets** — large positive *or* large negative payoff depending on context

> ⚠️ **Do not reveal the negative implications of the Reserve Big Bets corner yet.** Let participants plot first and discover the problem organically (Rule: No Pre-spoiling Reserve Big Bet).

### 4. Plot the Initiatives — Fast Round (10 min)
For each initiative in order, ask the user (or team) to simultaneously vote on **both axes** using the decision rules below. Spend no more than 30 seconds per initiative. Plot those with immediate consensus first.

**Bet type decision:**
- *No Regrets* → positive outcome in any scenario
- *Options* → small upfront cost, infrequent large upside
- *Big Bets* → can yield large positive **or** large negative payoff

**Posture decision:**
- *Shape* → sets standards, creates demand, seeks leadership
- *Adapt* → fast second-mover, existing market capture
- *Reserve* → minimal commitment, avoids premature bets

Output a running placement table as initiatives are classified, e.g.:

| Initiative | Bet | Posture | Cell |
|---|---|---|---|
| Initiative A | Options | Shape | Shape Options ★ |
| Initiative B | Big Bets | Reserve | Reserve Big Bets ⚠️ |

### 5. Slow Round — Contested Placements
Identify any initiatives the user flagged as uncertain. For each, display two or three already-plotted initiatives as reference anchors and ask the user to compare directly ("Is Initiative X more or less risky than Initiative Y?"). Finalize the placement.

### 6. Take Stock and Adjust (5 min)
Present the full populated matrix. Ask: "Does any initiative feel misplaced relative to its neighbours?" Apply any adjustments to match group consensus. Confirm the final grid before proceeding to decisions.

### 7. Apply the Four Decisions

#### Decision 1 — Delegate all No Regrets
Identify every initiative in the bottom row (No Regrets). Instruct the user to **remove these from the senior team's agenda** and assign them to junior team members to execute and maximize. List them explicitly:

> **Delegated (remove from senior agenda):** [list]

#### Decision 2 — Destroy all Reserve Big Bets
Identify every initiative in the top-right cell. For **each one**, run the Transform workflow:

1. Present the three improvement directions:
   - **(a) Move Down → Options:** Split into successive stages; invest only after earlier stages succeed.
   - **(b) Move Left → Adapt:** Redesign to deliver greater, more differentiated benefit.
   - **(c) Move Down-and-Left → Shape Options:** Apply both (a) and (b) simultaneously.
2. Generate candidate new versions for each direction using team knowledge — not big data.
3. Show each new version on the matrix with a **different colour Post-it** (or label) from the original.
4. Select the version (or Glide Path sequence) whose position is closest to Shape Options.
5. Confirm the top-right corner is empty before proceeding.

> **Rule: The Reserve Big Bets cell must always be empty when the session closes.**

#### Decision 3 — Discuss all Shape Big Bets
Identify every initiative in the top-left cell (Shape, Big Bets). Flag these for **substantive senior management debate**. For each, explore: *Can this be re-engineered into an Options-based approach?* If yes, generate the improved version and Drag it toward Shape Options. If not yet resolvable, mark it for a dedicated follow-up discussion.

#### Decision 4 — Drag remaining initiatives toward Shape Options
For every initiative not yet delegated or destroyed, propose an improved version that reduces risk and/or increases reward. Show the Glide Path: starting cell → intermediate cell(s) → target cell. Use distinct labels for each step (e.g. "Initiative C v1 → Initiative C v2 → Shape Options").

### 8. (Optional) Digital App
If there are more than 15 initiatives, or if capturing multi-step Glide Paths for stakeholder presentation is a priority, recommend: **www.strategic.how/payoff**

### 9. Summarize the Optimized Portfolio
Produce a final summary table:

| Initiative | Original Cell | Decision | New Cell / Glide Path |
|---|---|---|---|
| … | … | Delegate / Destroy / Discuss / Drag | … |

State clearly how many initiatives are now at or near Shape Options, how many were delegated, and whether any Reserve Big Bets remain.

---

## Verify

The session is complete and successful when **all** of the following are true:

1. **Reserve Big Bets corner is empty.** No initiative remains in the top-right cell.
2. **No Regrets row is cleared from the senior agenda.** Every initiative in the bottom row has a named delegate.
3. **Shape Big Bets have a decision.** Each top-left initiative is either re-engineered toward Shape Options or has a scheduled discussion owner and date.
4. **All remaining initiatives have a Glide Path.** Every surviving initiative has at least one improved version plotted on the matrix, moving it toward Shape Options.
5. **The summary table is complete.** Every initiative from Step 2 appears in the final table with a Decision and New Cell.

Ask the user to confirm the summary table looks correct before closing.

---

## Watch out for

- **Reserve Big Bet anti-pattern** — If any initiative is left in the top-right corner at close, the session has failed its primary objective. Do not accept "we'll revisit it" as a resolution.
- **HiPPO Curse** — If one participant dominates placement votes, call for simultaneous voting (rock-paper-scissors style) to surface genuine team judgment. See [anti-patterns catalog](../skills/strategic-thinking/references/anti-patterns/anti-patterns-catalog.md).
- **Data-holic** — Resist requests to spend more than 30 seconds per initiative during the fast round. The goal is relative positioning, not analytical precision.
- **Pre-spoiling** — Do not explain the Reserve Big Bets penalty before plotting. The organic discovery is the engine of the optimization value (Rule: No Pre-spoiling Reserve Big Bet).
- **Too many initiatives** — If the list exceeds 15, recommend the digital app at www.strategic.how/payoff and use colour-coding to track Glide Path evolution.

## Notes

- The Payoff Profiles Matrix is a **Down-phase tool** in the Rollercoaster framework. Run it after Up-phase ideation (Pyramid Principle, Happy Line, Mutation Game) has generated candidate initiatives. See [Rollercoaster Framework](../skills/strategic-thinking/references/core/rollercoaster-framework.md).
- **Russian Dolls Quality:** The matrix can be applied recursively — company-wide, then business-unit level, then functional/team level. Consider running multiple nested sessions for large organizations.
- For Glide Path design on complex initiatives, combine with the Lean Startup experiment workflow to validate intermediate steps before committing. See [design-lean-experiment.md](design-lean-experiment.md).
- For the full matrix reference including cell definitions, the Four Decisions detail, and the Reserve Big Bet anti-pattern, see [Payoff Profiles reference](../skills/strategic-thinking/references/tools/payoff-profiles.md).
- For facilitation tips on team sizing, Post-it conventions, and managing contested votes, see [Facilitation Tips](../skills/strategic-thinking/references/topics/facilitation-tips.md).
