# strategic-thinking-toolkit

A [Claude Code](https://docs.anthropic.com/en/docs/claude-code) plugin based on *How to be Strategic* by Fred Pelard.

A structured strategic thinking plugin based on Fred Pelard's 'How to Be Strategic', providing the Up–Down–Push Rollercoaster framework, ten named strategy tools, and facilitation workflows for tackling complex, future-oriented problems.

## Install

```bash
claude plugin marketplace add owner/repo
claude plugin install strategic-thinking-toolkit@strategic-thinking-toolkit
```

*Replace `owner/repo` with the GitHub repository after publishing with `franklin push`.*

## Agents

- **strategy-reviewer** — A reviewer agent that evaluates a strategic plan, initiative portfolio, or problem-solving approach against the book's comprehensive anti-pattern catalog.
- **strategy-planner** — A planner agent that sequences the Up–Down–Push Rollercoaster process for a given strategic challenge.
